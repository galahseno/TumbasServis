## Goal

Design first-launch and login: splash, 3-slide onboarding (value prop of the multi-vehicle booking), phone login and mock OTP (demo code `123456`), with tablet layouts that reflow rather than letterbox.

## Inputs

- `TsLogo` (mark, mark + wordmark lockups, splash mark — step 02), `TsTextField` (`+62` prefix, error), `TsButton` (primary / ghost / loading), `PageIndicator`, `TsAppBar / Type=Back`, `TsSnackbar`, silhouettes / `UnitStatusBadge` / `FleetProgress` (onboarding vignettes), `System / Keyboard` (step 07a; a numeric pad is built here for the phone / OTP fields).
- Onboarding copy from PRD 04: (1) "Servis banyak motor, sekali booking", (2) "Atur servis & keluhan tiap motor secara terpisah", (3) "Pantau status tiap unit secara real-time".
- P1 rule: default + empty + one loading/error per screen; dark = default on each breakpoint.
- Demo data: `+62 812-3456-7890` (masked `+62 812-****-7890`), OTP `123456`.

### Annotations to place

- Splash: ≥ 800 ms minimum, session check → S02 (first launch) or S05 (returning); wordmark fades in after ~400 ms, static under reduce-motion.
- Onboarding: swipe or CTA; "Lewati" jumps to S03; last slide CTA "Mulai"; page indicator is a position cue (semantics "Slide 1 dari 3"), not a control.
- Login validation rules (9–12 digits, leading 0 dropped, grouping as typed); loading = `TsButton` spinner, field locked; network error = snackbar copy above.
- OTP: wrong code → shake (skipped under reduce-motion) + clear + focus cell 1; resend disabled 30 s; demo code `123456` behind a demo flag; no auto-submit; SMS auto-fill out of scope.
- Keyboard: content scrolls above the keyboard on S03 / S04, CTA follows the inset.
- Semantics: icon-only controls (back, clear) carry `Semantics` labels; OTP cells announce "Digit 1 dari 6".
