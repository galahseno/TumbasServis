## 3. html2figma options that worked (step 01 spike, step 04 test import)

- Export: `Export(frameId, "html-css", "./design/pencil/exports/html/<step>/<frame>.html", {includeLayerNames: true})`, **one frame per file** (several frames share an absolutely positioned wrapper that imports as an extra parent).
- Import: drag the `.html` into html2figma with **Auto Layout on**; fonts load from Google Fonts (Exo 2, weights 400 / 600 / 800; 700 is not loaded).
- Pre-check each file in Chromium (Playwright) against the Pencil PNG before the user imports.
- The export carries **no components, no variables, no themes**: instances are plain frames, colors are resolved hexes, a dark frame is another resolved frame.
- Strokes must be `strokeAlignment: "inner"` (center exports as CSS `outline`, which converters can drop). **Step 19 fixed the last non-inner frame / rectangle strokes** (25 in `00 Cover`, `98 Demo Content` and the Invoice & Review masters, plus 16 focus-specimen refs). Remaining non-inner strokes are `path` / `ellipse` nodes (SVG art, Star paths, motion curve), which export as SVG.
- `background_blur` radius is `$glass-blur` = 28 everywhere (46 uses) → CSS `blur(14px)`.
- `note` nodes are not exported: recreate the 251 notes (134 sit in the `S## Handoff Notes …` frames — S01 2, S02 2, S03 3, S04 2, S05 6, S06 5, S07 3, S08 4, S09 4, S10 6, S11 7, S12 4, S15 8, S16 9, S17 5, S18 7, S19 11, S20 8, S21 7, S22 7, S23 7, S24 6, S25 5, S26 6 — and 117 sit in component sheets / foundations boards, including the six S13 / S14 notes in the `S13 S14 Blocks` sheet) as Figma comments or sticky notes.
