   **Answered:** await the min-duration timer first, then await the (already-kicked-off) session-check future — this naturally resolves to whichever finishes last, since the session check starts concurrently at `build()` time.
2. OTP 6-cell input — a hand-rolled `Row` of 6 `TextField`s with auto-advance/auto-paste, or a package (`pin_code_fields` or similar)? Recommend hand-rolled per the skill's "prefer the reference stack, swap only if needed" — keeps the widget tree simple and matches `OtpInput`'s exact design spec (focused/filled/error/loading).
   **Answered:** hand-rolled, as recommended.
3. Onboarding "Lewati" / swipe — `PageView` + `PageIndicator`; confirm skip jumps straight to `/login` per PRD 03.
   **Answered:** confirmed, both "Lewati" and slide-3's "Mulai" go to `/login`; "Lewati" hidden on slide 3.
4. **(New, surfaced at kickoff)** `design/pencil/exports/step13/` didn't exist on disk despite the design docs claiming export — no PNG reference available at kickoff time. **Answered:** build from the design doc's resolved text spec (copy/states/components fully extracted), same precedent as step 10. The user has since regenerated the export folder; PNGs were consulted per-screen (one or two at a time, not all 33 at once) as each screen was built, to keep token use down across this and future sessions.
5. **(New)** "Kode demo: 123456" hint gating — PRD/design say "demo build only" / "behind a demo flag," but no flavor infra exists in the repo. **Answered:** gate with `kDebugMode` — zero new infra, matches intent.
6. **(New)** S04 "Verifikasi" CTA: real disabled button, or always-enabled with a reason line only on invalid tap (the design doc's own unresolved LOW finding)? **Answered:** real `onPressed: null` while <6 digits, with a static "Masukkan 6 digit kode" line always visible while disabled — matches PRD 03's count-gated-CTA rule.
